CharmPkk — это многофункциональная библиотека для Python, которая объединяет в себе инструменты для создания красивых консольных интерфейсов, оконных приложений на tkinter, а также продвинутой работы с файлами, сетью, безопасного чтения памяти процессов и даже встроенного консольного и оконного браузера. Библиотека не требует установки тяжелых сторонних зависимостей, всё необходимое уже есть в стандартной библиотеке Python, а работа с архивами вынесена в опциональные пакеты.



Для базового функционала установите библиотеку командой pip install CharmPkk. Для максимальных возможностей, включая работу с 7z, rar, корзиной и Brotli, используйте pip install "CharmPkk\[full]". Обратите внимание, что текущая версия является бета-релизом, поэтому для установки может потребоваться флаг --pre.



CharmPkk состоит из трех независимых слоев, которые можно использовать как вместе, так и по отдельности. Первый слой — S()eclipse — это автоматизация и работа с файлами. Он идеально подходит для установщиков, скриптов и бэкенда, так как не содержит визуального мусора. Он умеет копировать и синхронизировать папки, искать дубликаты и текст внутри файлов, удалять файлы в корзину. Также он работает с архивами zip, tar, 7z и rar, умеет скачивать файлы с докачкой, имитировать реальный браузер для обхода блокировок и проверять доступность интернета. В этом обновлении были добавлены функции поиска самого нового и самого тяжелого файла в директории, а также безопасное чтение JSON.



Второй слой — Xeron — это визуал и пользовательский интерфейс. Он позволяет создавать красочные консольные интерфейсы и оконные приложения. В консоли доступно более 20 цветовых тем, рамки, таблицы, графики, спиннеры, прогресс-бары, анимации текста и даже частицы. Баннеры теперь поддерживают многопанельные градиенты (Cyberpunk, Ocean, Vaporwave и другие). В оконном режиме на tkinter доступны современные карточки, формы ввода, таблицы с сортировкой и поддержка акрила для Windows. Кроме того, в Xeron встроен полноценный консольный и оконный браузер с поиском через DuckDuckGo, чтением текста, кликабельными ссылками, закладками и возможностью сохранения статей в файл. Оконный браузер получил улучшенный интерфейс с кнопками навигации назад и вперед, а также обновленный парсинг статей для более удобного чтения. Также был добавлен модуль MemoryReader для безопасного чтения памяти процессов в режиме Read-Only без сторонних библиотек.



Третий слой — XeronLegacy — это комбайн, который объединяет визуал и файлы. Он идеально подходит для создания красивых установщиков с прогресс-барами, анимациями шестеренок и экранами завершения.



После установки в системе появляется команда revck (или python -m charmpkk.revck). Это интерактивный учебник, тест целостности и песочница, где можно попробовать все модули библиотеки в деле. В revck появился новый раздел поддержки, где можно связаться с автором напрямую. Также была расширена система тестирования, которая теперь проверяет сеть, чтение памяти, парсинг браузера и работу с архивами.



В библиотеке есть два расширяемых терминала: Collquan и Pretmod. Collquan позволяет создавать свои Python-команды прямо на лету через блоки, сохранять их в файлы и загружать обратно. В версии 28.10.26b2 в терминалах появились история команд и возможность создания псевдонимов (алиасов) для быстрого вызова часто используемых функций. Также добавлен собственный текстовый формат .cllqn для автоматизации в Collquan. Это простой файл, в котором можно писать команды и директивы, такие как sleep для паузы, ask для запроса ввода и подстановка переменных. Запустить скрипт можно командой run, а проверить синтаксис командой lint.



Вы можете запускать collquan и pretmod прямо из окна "Выполнить" (Win+R), просто вписав их названия. Важно, чтобы папка Scripts вашего Python была добавлена в переменную среды PATH. При возникновении ошибки окно терминала не закроется мгновенно, а покажет трейсбек и попросит нажать Enter.



Для работы требуется Python 3.8+. tkinter встроен в Python и нужен для оконного режима. Опционально можно установить py7zr, rarfile и brotli для полноценной работы с архивами. Если нашли баг или есть предложение — пишите на почту reception.mailspypi@gmail.com.
